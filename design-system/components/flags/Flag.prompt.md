Country flag glyph (262 flags from the Figma Country Flags page) — use in phone-number prefixes, currency/country selects and InlineSelect.

```jsx
<Flag name="Indonesia" size={20} />
<Indonesia size={16} />
```

Names are PascalCase country names (UnitedStates, SaudiArabia…). See Flag.d.ts for the full list.
